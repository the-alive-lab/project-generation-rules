# Checklist de generación de proyectos

Checklist flexible: **no todos los ítems son obligatorios** para un proyecto exploratorio.

- [ ] Se verificó que no existe ya una superficie equivalente.
- [ ] README explica problema, propósito, audiencia, alcance y estado.
- [ ] README permite navegar a las superficies existentes.
- [ ] Se distinguen definición vigente, propuesta, evidencia y decisiones pendientes.
- [ ] Está identificada la fuente canónica y quién tiene autoridad sobre cambios.
- [ ] La estructura se justifica por responsabilidades reales.
- [ ] Hay instrucciones de uso, ejecución o contribución si aplican.
- [ ] AGENTS.md orienta colaboración automatizada si aplica.
- [ ] llms.txt indexa fuentes reales si la audiencia incluye LLM.
- [ ] Se comprueba consistencia y ausencia de enlaces rotos.
- [ ] No se publican secretos, datos personales ni material sin permiso.
- [ ] Visualizaciones tienen interpretación textual y límites cuando se usan.
- [ ] La siguiente acción y el estado pendiente se pueden descubrir sin el chat original.
