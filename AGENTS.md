# Orientación para agentes — Project Generation Rules

Este repositorio recopila recomendaciones compartidas de generación de proyectos para The Alive Lab. **No es un generador ejecutable ni impone sus reglas automáticamente a proyectos consumidores.**

## Orden de lectura

1. [README.md](README.md) para propósito y alcance.
2. [rules/project-foundation.md](rules/project-foundation.md) para fundamentación y estructura.
3. [rules/human-and-agent-discovery.md](rules/human-and-agent-discovery.md) para descubrimiento.
4. [guides/bootstrap.md](guides/bootstrap.md), [guides/evolution.md](guides/evolution.md) y [checklists/new-project.md](checklists/new-project.md) según tarea.

## Al contribuir

- Mantén consistentes README, AGENTS.md, llms.txt y enlaces.
- Evita imponer una única estructura o tipología a todos los proyectos.
- Valida que los ejemplos no prometan capacidades automáticas que no existen.
- No declares aprobada una convención propuesta ni sobrescribas autoridades de otros repositorios.
- Prioriza cambios pequeños, trazables y editables. Si una regla cambia semánticamente, explica motivo y compatibilidad.
- Para gráficos, consulta [Visualization Rules](https://github.com/the-alive-lab/visualization-rules).
- No escribas ni publiques automáticamente en repositorios consumidores sin autorización explícita.

Estas instrucciones orientan el trabajo en **este repositorio** y no sustituyen instrucciones superiores ni la autoridad del proyecto consumidor.
